# feed_daily

Static dashboard generator for daily market-data stats.

## Input Data

Reads stats tables generated by `shm_dump_to_parquet`:

```text
<stats-root>/<YYYY>/<MMDD>/
  summary.json
  summary.csv
  datatype.csv
  exchange.csv
  symbol.csv
```

## Run

```bash
cd /home/jdlee/repos/trading-dashboard
python3 -m pip install -e .
python3 -m feed_daily \
  --stats-root /mnt/bigdata2/Ferris/stats \
  --output-root /tmp/feed_daily_dashboard \
  --host 127.0.0.1 \
  --port 8020
```

Open `http://127.0.0.1:8020/`.

## Notes

- Serving is enabled by default. Use `--no-serve` to build and exit.
- Watch mode is enabled by default while serving.
- Use `--no-watch` to disable periodic rebuild checks.
- Default watch interval is 10 minutes (`--watch-interval 600`).

Example:

```bash
python3 -m feed_daily \
  --stats-root /mnt/bigdata2/Ferris/stats \
  --output-root /tmp/feed_daily_dashboard \
  --watch
```

Disable watch:

```bash
python3 -m feed_daily \
  --stats-root /mnt/bigdata2/Ferris/stats \
  --output-root /tmp/feed_daily_dashboard \
  --no-watch
```
- Snapshot metrics are packet-level counts from dump-derived stats files.
